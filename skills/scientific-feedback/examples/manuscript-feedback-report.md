# Manuscript Feedback Report

Use this as an output pattern for integrated manuscript feedback.

## Completed closed fictional critique

**Given.** A fictional Results paragraph says “Compound K improves organism survival.” The supplied study reports an altered cultured-cell response after compound exposure compared with control, with no direction supplied here; no organism experiment or survival endpoint was measured. The supplied figure description says it plots cell response, while the legend calls the points “independent experiments” without defining the unit. The actual image and analysis record are unavailable. The author requests a quick integrated check of the claim and evidence display before sending the draft to a collaborator, without designing new experiments.

**Completed feedback.** The paragraph and figure description address the same cellular response, which is the useful core to preserve. First, replace the survival claim with “Compound K altered the measured cellular response under these culture conditions,” retaining the measured direction if it is supplied. Then define what a plotted point represents from the actual experiment record; the legend alone does not establish independence. These two changes connect the claim to the evidence and make the comparison assessable. I cannot judge palette, layout or whether the analysis used the correct unit without the image and analysis record. This pass does not establish organism benefit or call a reporting correction completed.

**Integration.** Writing and figure-evidence lenses serve one repair sequence. Publication-process advice is unnecessary for the requested collaborator check. No fixed report headings or invented experiment are needed.

## Pattern

Use relevant fields only; omit empty categories for a short review.

```text
Scope: manuscript draft for <audience/destination>.
Selected lenses: scientific-writing; add data-visualization-and-figures or publishing-and-peer-review if relevant.

What works:
- <strength to preserve>

Must fix first:
1. <issue -> action -> rationale>

Major revisions:
1. <section/claim/evidence issue -> specific revision>
2. <figure/table/legend issue -> specific revision>

Secondary improvements:
- <style, flow, or consistency issue>

Missing context:
- <journal, figure, data, or audience detail that would change advice>

Next revision step:
- <ordered action>
```

## Weak vs strong

Weak: "The paper is hard to follow and needs better flow."

Strong when research chronology obscures the argument: "Orient each subsection around its question or finding, then the comparison and evidence needed to assess it. Retain essential design context. Move broader interpretation to the Discussion when the journal separates those sections; an integrated Results and Discussion can keep it beside the evidence."

## Bad assistant behavior

- Rewriting paragraphs before diagnosing section function.
- Treating figure problems as prose problems only.
- Listing every minor wording issue before the central claim is stable.
