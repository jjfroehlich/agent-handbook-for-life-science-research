# Grant Writing Templates

Select relevant fields when the user asks for a structured review, rubric, table, or rewrite plan. A narrow edit does not need every table. Record the supplied evidence and its status; leave unresolved facts explicit.

## Funder-Fit Preflight

```text
Funder and mechanism:
Call scope:
Applicant eligibility:
Required sections:
Template and formatting constraints:
Review criteria:
Budget cap and allowed costs:
Internal deadline:
Evidence still needed:
Decision: proceed / retarget / clarify
```

## Active Premise And Why Questions

```text
Objective:
Active premise:
Why this problem:
Why now:
Why this approach/model/system:
Why this applicant/team/environment:
Expected change if successful:
```

## Approach Block

```text
Aim or work package:
Rationale:
Overall plan:
Specific example or preliminary data:
Evidence status and tested scope:
Interpretable outcomes:
Potential issue:
Credible alternative or qualification gate, if needed:
```

## Budget Feasibility Check

```text
Promised work:
Required personnel/resources:
Requested funds:
Allowed and disallowed costs:
Delivery risk if underfunded:
Rescope decision:
```

## Risk-Return-Feasibility Row

```text
Ambitious claim:
Expected scientific return:
Scientific risk:
Execution evidence and unresolved development:
Feasibility evidence:
Reviewer doubt to address:
```

## Bold-Statement Skim Test

```text
Read only headings:
Read only topic sentences:
Read only figure titles/captions:
Read only bolded statements:
Can the reviewer recover the proposal gist?
Statements to rewrite or unbold:
```

## Protocol And Budget Preflight

| Check | Evidence in draft | Risk if missing | Fix |
|---|---|---|---|
| Hypothesis/goal | | Reviewer cannot tell what success means | Add explicit objective and outcome |
| Controls/analysis | | Feasibility looks underplanned | Add controls, analysis plan, and rationale |
| Funder budget fit | | Costs or scope do not match the call | Check current cost rules and reconcile justified costs with scope |
| LOI consistency, if applicable | | Full proposal changes an earlier request | Explain scope and amount changes under the actual process |
